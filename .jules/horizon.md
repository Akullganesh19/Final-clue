## 2024-07-15 — CI and Build Tooling Modernization
**Risk identified:** The GitHub Actions CI pipeline (.github/workflows/webpack.yml) attempts to run tests on Node.js 18 (which lacks support for Vite 6 and @google/genai used in this project) and invokes a non-existent `webpack` build step despite the project actually using Vite and esbuild. This causes pipeline failures and reflects an outdated architectural mindset that will confuse future developers expecting the actual build tools to be used.
**Migration target:** Modernization of the CI pipeline to use Node.js 20+ and proper execution of the project's native build tools (Vite/esbuild via `npm run build`), ensuring accurate continuous integration checks.
**Migrated this session:** Updated `.github/workflows/webpack.yml` to remove Node.js 18 from the matrix and replaced `npx webpack` with `npm run build`. Created minimum viable stubs for `src/App.tsx` and `server.ts` to ensure build succeeds structurally. Configured native node test runner with tsx.
**Remaining:** Verify all repository modules for any remaining unused or deprecated tool configurations (e.g., old Webpack configs if any exist) and migrate them to standard Vite/esbuild configurations.
**Next session:** Investigate frontend testing approaches using Vite-native tools (like Vitest) if testing complexity grows beyond the currently configured native Node.js test runner.
