## 2024-03-22 — Cross-Case Entity Intelligence
**Product understood as:** A multi-agent cold case system that stores rich structured entity data across multiple investigations.
**Derivation reasoning:** This product has cases with rich arrays of extracted entities (people, vehicles, weapons, locations). Users investigate cold cases to find links. Therefore users obviously need a cross-case entity dashboard — because they need to easily spot when the same suspect, vehicle, or weapon appears in multiple supposedly unrelated cases, which is the exact definition of a "final clue". It doesn't exist because the system currently focuses on individual case linkage scoring rather than global entity aggregation. I'm building it because giving investigators an automatic pivot on recurring entities will massively accelerate cold case solving.
**Feature built:** A React dashboard component (`CrossCaseEntityDashboard`) and backend aggregation utility (`analyzeCrossCaseEntities`) that scans all cases and surfaces entities (normalized case-insensitively) that appear in more than one case, complete with their frequency count and linked case IDs.
**User impact:** Investigators can now immediately see if a specific "White Van" or ".38 Caliber Revolver" appears in multiple cold cases, serving as a direct pivot for their investigations.
**Next logical feature:** An interactive timeline view mapping when and where these recurring entities were spotted chronologically.
