## 2026-07-02 — Case Clustering (Macro Pattern Detection)
**Product understood as:** A cold case linkage system that currently analyzes pairwise connections between individual cases.
**Derivation reasoning:** The system already stores pairwise linkages between cases. As investigators link more cases, logical macro patterns naturally form (A->B, B->C means A, B, and C are related). Therefore, users obviously need a way to view and interact with these macro groups, rather than just isolated pairs, to understand serial patterns.
**Feature built:** Added `CaseCluster` type and a `findCaseClusters` utility that uses graph traversal (connected components) to automatically group cases into clusters based on non-rejected pairwise linkages. UI implementation will follow in a subsequent phase once the backend logic is stabilized and vetted by the broader architecture, as we currently lack the UI scaffolding (e.g. `App.tsx` and routing) for it.
**User impact:** The core domain logic now natively supports identifying broad serial patterns out of isolated linkages, enabling downstream features to surface these macro patterns.
**Next logical feature:** The next logical feature would be the user-facing UI component (like a visual network map or a cluster list view) that renders these macro clusters so users can interactively explore them, once the foundational UI components are established.
