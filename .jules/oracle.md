## 2025-03-05 — Next-Action Prediction Engine
**Product understood as:** A multi-agent case-linkage & evidence-triage system for cold cases.
**Prediction invented:** A Markov chain based Next-Action Prediction engine that predicts and prefetches the user's next logical action based on audit log transitions.
**Data used:** The existing `AuditTrail` action sequences, matching current and next actions.
**Impact:** Impossibly fast perceived load times as resources for the next predicted view/action are prefetched before the user even requests them.
**Next opportunity:** Predicting intelligent default values for new evidence triage based on historical categorizations.
